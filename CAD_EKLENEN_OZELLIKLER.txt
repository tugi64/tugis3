## ✅ Eklenen Özellikler

### 1. Zoom Extents (Projenin Tümünü Gör)
**Konum:** Sol Toolbar - En üstte
**İkon:** ZoomOutMap (büyütme ok ikonu)
**Etiket:** "Tümü"

**Ne Yapar:**
- AutoCAD'deki "Z" + "E" (Zoom Extents) komutu gibi çalışır
- Tüm CAD nesnelerinin sınırlarını hesaplar (min/max E, N koordinatları)
- Projenin tamamını ekrana sığdırır
- Proje boyutlarını gösterir (örn: "125.5m x 85.3m")

**Nasıl Çalışır:**
```
1. Kullanıcı "Tümü" butonuna basar
2. CadViewModel.computeProjectBounds() çağrılır
3. Tüm entities (Point, Line, Polyline, Circle, Arc, Polygon) taranır
4. Min/Max koordinatlar bulunur
5. Merkez noktası hesaplanır
6. Snackbar mesajı: "Proje: 125.5m x 85.3m - Merkez gösteriliyor"
7. (TODO: Map kamerasını bounds'a göre ayarla)
```

**Kod:**
- CadViewModel.kt: `computeProjectBounds()` fonksiyonu
- CadApplicationActivity.kt: "Tümü" butonu (satır ~370)

### 2. Arka Plan Rengi Değiştirme
**Konum:** Sağ Toolbar > Araçlar Menüsü > Görünüm Araçları > Arka Plan Rengi
**İkon:** Palette (palet ikonu)

**Ne Yapar:**
- CAD çizim alanının arka plan rengini değiştirir
- 10 farklı renk seçeneği sunar
- Seçili renk vurgulanır (kalın border)
- Göz yorgunluğunu azaltan koyu renkler önerilir

**Renk Seçenekleri:**
```
Siyah        (0xFF000000)
Koyu Gri     (0xFF1A1A1A)
Gri          (0xFF2C2C2C)
Beyaz        (0xFFFFFFFF)
Açık Gri     (0xFFF5F5F5)
Koyu Mavi    (0xFF0D47A1)
Mavi         (0xFF1976D2)
Açık Mavi    (0xFF1E88E5)
Koyu Yeşil   (0xFF004D40)
Yeşil        (0xFF00695C)
```

**Nasıl Kullanılır:**
```
1. CAD Aplikasyonu aç
2. Sağ toolbar'dan "Araçlar" (Build ikonu) butonuna bas
3. "Görünüm Araçları" bölümünde "Arka Plan Rengi" seç
4. Dialog açılır
5. İstediğin rengi seç
6. Anında uygulanır
7. Mesaj: "Arka plan rengi değiştirildi"
```

**Kod:**
- CadViewModel.kt:
  - `backgroundColor: StateFlow<Long>` state
  - `setBackgroundColor(color: Long)` fonksiyon
- CadApplicationActivity.kt:
  - `BackgroundColorDialog` composable (dosya sonu)
  - Dialog state management

### 3. Zoom In/Out Fonksiyonları
**Konum:** Sol Toolbar (Tümü butonunun altında)

**Özellikler:**
- Zoom In: Haritayı 1.2x yakınlaştırır (max 22x)
- Zoom Out: Haritayı 1.2x uzaklaştırır (min 8x)
- lastZoom state'i günceller

**Kod:**
- CadViewModel.kt:
  - `zoomIn()` fonksiyon
  - `zoomOut()` fonksiyon

**Eklenen Fonksiyonlar:**
