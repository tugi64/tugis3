🔧 ADIM 1: DOSYAYI AKTİVE EDİN

   Android Studio'da:
   1. CrossSectionMeasurementActivity_NEW.kt dosyasını açın
   2. CTRL+A (Tümünü Seç)
   3. CTRL+C (Kopyala)
   4. CrossSectionMeasurementActivity.kt dosyasını açın
   5. CTRL+A (Tümünü Seç)
   6. CTRL+V (Yapıştır)
   7. CTRL+S (Kaydet)

🔧 ADIM 2: BUILD

   1. Build → Clean Project
   2. Build → Rebuild Project
   3. Hata kontrolü yapın

🔧 ADIM 3: TEST

   1. Run → Run 'app'
   2. Emulator veya cihazda açın
   3. Ana Menü → Survey → Kesit Ölçümü
   4. GPS izinlerini verin
   5. Test senaryolarını çalıştırın
